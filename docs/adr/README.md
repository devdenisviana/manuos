# Registros de decisão de arquitetura (ADRs)

Cada ADR registra uma decisão importante do projeto: o contexto, a decisão tomada, as alternativas consideradas e as consequências. Uma ADR aceita não é editada depois; se a decisão mudar, cria-se uma nova ADR que substitui a anterior, e o status da antiga passa a "Substituída pela ADR NNNN".

Para criar uma nova ADR, copie [`0000-modelo.md`](0000-modelo.md) com o próximo número.
