# Diário de desenvolvimento

Registro curto de cada sessão de trabalho: o que foi feito, problemas encontrados e como foram resolvidos. Serve de base para os capítulos de desenvolvimento do TCC.

Um arquivo por mês (`AAAA-MM.md`), com entradas em ordem cronológica. Modelo de entrada:

```markdown
## DD/MM/AAAA — Título curto da sessão

**Feito:** o que foi realizado.
**Problemas:** o que deu errado, mensagens de erro relevantes.
**Solução:** como foi resolvido, ou o que ficou pendente.
**Aprendizado:** algo que vale lembrar ou citar no texto.
```
